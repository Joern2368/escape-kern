# Escape-Room-Kern

Spieldateien für Escape Games, die in einer kleinen HTML-Datei per `<script src>` geladen werden.

- `v1/`: Engine (`engine.js`), Design (`spiel.css`) und 23 Szenarien (`szenario-<kennwort>.js`)
- `fonts/`: Schrift Andika
- Wurzel (`zirkus.css`, `zirkus-szenario.js`, `engine.js`): erster Test mit dem Zirkus

Die Dateien enthalten keine Schülerdaten und sprechen keine anderen Server an.
Lizenz: MIT (siehe `LICENSE`), Schrift Andika: SIL OFL 1.1 (`fonts/OFL.txt`).
