# 3D-Welten

Spieldateien für begehbare 3D-Welten (Lern-Rätselspiele), die in einer kleinen HTML-Datei per `<script src>` geladen werden.

- `v1/engine.js`: Spiel-Engine (Figur, Kamera, Rätseltypen, Wissensmappe, Finale, Urkunde)
- `v1/spiel.css`: Design
- `v1/welt-<kennwort>.js`: je eine Welt (Landschaft, Tiere, Gebäude): alpen, bauernhof, freizeitpark, insel, stadt, wald, zoo
- Die 3D-Bibliothek three.js (MIT-Lizenz) lädt die HTML-Datei von cdnjs.

Die Dateien enthalten keine Schülerdaten und sprechen keine anderen Server an.
Schrift Andika (SIL OFL 1.1) liegt in `../fonts/`.
